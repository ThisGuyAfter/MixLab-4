# MixLab V4 — The Ultimate Mixing Encyclopedia

Mobile-first Progressive Web App for audio engineering, mixing, sound design and mastering reference.

## V4 direction
- Technical depth from beginner fundamentals through advanced audio engineering and DSP concepts.
- Extensive, expandable plugin directory with developer/product links and clearly changeable pricing/edition labels.
- Both standalone encyclopedia articles and structured learning paths.
- Searchable production glossary with cross-links to full articles.
- Preserves V3.2 instrument chains, genre profiles, sound-target recipes, plugin recommendations, chain builder, routing studio, troubleshooting, favorites, notes and local saved chains.

## V4 initial content
- 25 structured encyclopedia articles across audio fundamentals, processing techniques, instrument guides, mixing, genre context and mastering.
- 3 guided learning paths with locally saved milestone progress.
- 35 glossary terms with links to related articles.
- Expanded plugin catalogue, adding 40+ named plugin/instrument entries to the existing curated V3.2 arsenal.

## Content quality and verification
Plugin pricing, product editions, availability, platform support and compatibility change. Check the linked developer page before purchase or installation. Entries are curated reference information, not endorsements or claims of exhaustive coverage. Some technical articles are initial editorial content and should be expanded with diagrams, citations and further examples in future releases. Starting settings are examples, not universal presets.

## Deploy to iPhone
1. Upload the contents of this folder to a GitHub repository root.
2. In repository Settings → Pages, publish from `main` and `/ (root)`.
3. Open the resulting HTTPS URL in Safari.
4. Tap Share → Add to Home Screen.
5. For updates, deploy the new files and reload the app. The service-worker cache key is `mixlab-v4-0-encyclopedia`.

Favorites, notes, custom chains and learning-path progress are stored locally in the browser on that device. They are not synced to a server.

## Audio note
MixLab is an educational reference and chain-planning tool, not a DAW plugin host or real-time audio processor. Always audition changes, level-match comparisons, check mono compatibility and follow project delivery specifications.
